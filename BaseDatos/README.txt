BASE DE DATOS DEL PROYECTO - SISTEMA GRUPO 11

El sistema es único para todo el grupo.

Cada integrante desarrollará las tablas correspondientes
a su módulo utilizando Oracle.

Módulos del grupo:
- Inventarios
- Activos
- Contabilidad
- Mantenimiento

Archivos:
- inventario.sql
- activos.sql
- contabilidad.sql
- mantenimiento.sql

Cada integrante debe colocar en su archivo SQL las
sentencias CREATE TABLE, PRIMARY KEY, FOREIGN KEY,
SEQUENCE y demás objetos necesarios para su módulo.

Al finalizar el desarrollo, todos los scripts serán
integrados en SCRIPT_COMPLETO.sql para generar la
base de datos completa del sistema.

IMPORTANTE:
No modificar las tablas de otro módulo sin coordinación
previa con el grupo.
